# Scoring

The Scoring page explains every figure the badges on a password show. A score comes from the password alone, or from
the password and its hint, so a password reads the same on a card, in My list and a year later.

## Strength, Raw and bits

Three figures, by how much an attacker knows:

- **Raw:** the attacker knows nothing, and tries every combination of the characters used.
- **Strength:** the attacker knows English and the usual habits people have, but not this tool.
- **Bits:** the attacker knows this tool exactly. This figure belongs to the current session and is never saved.

A fourth badge, **zxcvbn**, is a second opinion from a widely used password checker, read as very weak, weak, good or
strong. The page also explains deliberate swaps, why a hint only ever lowers the bits, and how long a password would
take to guess.

## Difficulty, 0 to 100

How hard the password is to type, for the mode you chose: long reaches, jumps between rows, the same finger twice and
the Shift key all cost. The page lists the options each mode fills in, and the measurements behind them.

## Memorability, 0 to 100

How easy the password is to remember from its hint: a password that reads as a sentence scores well.
