# Features

Reviewed: 2026-11-24

What Elegant Passwords does for the people who use it. The Engineering Workspace's Features area holds the feature
catalogue, one file per feature in [features/](features/), with the routes each owns and the code it is built from;
this is its table.

| Feature | Status | What it does |
| --- | --- | --- |
| [Passwords](features/passwords.md) | live | The main page: a site's rules in, passwords that read as a sentence out, with a typing test and a saved list. |
| [Scoring](features/scoring.md) | live | The rubric behind every badge: Strength, Raw, bits, zxcvbn, Difficulty and Memorability. |
| [Fun](features/fun.md) | live | Two prompts, generated from the app's own settings, that rebuild the web app and then tep with an AI coding assistant. |
| [tep, the command line](features/tep.md) | live | The same passwords in a terminal: tep g generates, tep config writes a config file, tep uninstall removes the link. |
| [The core as a package](features/core-package.md) | EP-M1.1 | The shared core published as @salientform/elegant-passwords: a typing mode, a site preset and a few overrides in, checked suggestions out. |
